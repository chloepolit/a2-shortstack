Assignment 2 - Short Stack: Basic Two-tier Web Application using HTML/CSS/JS and Node.js  
===

## To Do List Manager
I designed this To Do List manager to allow users to fill out the form to add a task with a task name, daadline, creation date, and category. The table then calculates a priority level according to the number of days until the deadline to complete the task. Users can then view their to do lists and add/delete tasks as needed and completed.

## Technical Achievements
- **Tech Achievement 1**: The form updates the table each time. I attempted to move both the list and the form onto a page together but I encountered a lot of bugs trying so it moved me to keep them separate. I decided on making a derived priority list to highlight urgent tasks with a deadline in the next 24 hours, as well as a high, medium, and low priority ranking depending on deadline date.

### Design/Evaluation Achievements
- **Design Achievement 1**: I utilized Courier New font family to customize the site into a academic journal aesthetic. I kept the color scheme of the dark background given in the template and added styling using the advice given in the Mozilla Developer HTML Design Tutorial, an further customized the buttons and table to be organized and readable. Customizing each individual component allowed me to further understand how each component contributed to the overall design and aesthetic of the site.
